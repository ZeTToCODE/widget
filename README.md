# Виджет «Посещаемость ptmob.ru» для macOS

Нативный виджет WidgetKit (SwiftUI) для Mac на Apple Silicon (M4). Он читает
`https://ptmob.ru/people.num` (JSON) и показывает посетителей и просмотры
за сегодня, неделю, месяц и всё время, а в большом размере ещё и график за 7 дней.

| Размер  | Что показывает |
|---------|----------------|
| Малый   | посетители сегодня, просмотры, итог недели |
| Средний | сегодня + неделя / месяц / всего |
| Большой | всё выше + столбчатый график за последние 7 дней |

- Данные обновляются примерно раз в 15 минут (при ошибке сети — через 5).
- Без сети виджет показывает последние сохранённые данные со значком ⚠️.
- Клик по виджету открывает ptmob.ru.
- Кнопка «Обновить» в приложении сразу перезагружает виджет.

## Требования

- macOS 14 Sonoma или новее
- Xcode 15 или новее (бесплатно в App Store)

## Установочный файл PtmobStats.dmg

Собрать `.dmg` можно только на macOS (нужен Xcode). Есть два способа.

**A. Без Mac под рукой — через GitHub Actions (бесплатно).**
1. Создайте на github.com пустой репозиторий и загрузите туда эту папку
   (через GitHub Desktop или `git push`).
2. Сборка запустится сама (файл `.github/workflows/build-dmg.yml`). Через ~5 минут
   откройте вкладку **Actions** → последний запуск → **Artifacts** → `PtmobStats-dmg`.

**B. На любом Mac:**

```bash
chmod +x make_dmg.sh && ./make_dmg.sh
```

Готовый образ появится в `dist/PtmobStats.dmg`.

**Установка из DMG:** откройте образ, перетащите `PtmobStats.app` в «Программы».
Приложение не нотарифицировано Apple, поэтому при первом запуске сделайте правый клик →
«Открыть» → «Открыть». Если macOS пишет, что приложение «повреждено», выполните
`xattr -dr com.apple.quarantine /Applications/PtmobStats.app`.

## Установка (на Mac)

Скопируйте папку на Mac и выполните в Терминале:

```bash
cd widgetMacos
chmod +x build.sh
./build.sh
```

Скрипт поставит XcodeGen (через Homebrew), сгенерирует проект, соберёт его под arm64,
скопирует `PtmobStats.app` в `/Applications` и запустит. Затем:
правый клик по рабочему столу → **«Изменить виджеты…»** → найдите **«Посещаемость ptmob.ru»**.

### Через Xcode

```bash
brew install xcodegen && xcodegen generate && open PtmobStats.xcodeproj
```

В Xcode для обеих целей (PtmobStats и PtmobWidget) на вкладке **Signing & Capabilities**
выберите свою команду (подойдёт бесплатный Apple ID) и нажмите ⌘R.

## Если виджет не появился в списке

1. Убедитесь, что приложение лежит в `/Applications` и было запущено хотя бы раз.
2. Перезапустите службу виджетов: `killall chronod NotificationCenter`
3. Если не помогло — соберите через Xcode с подписью Apple ID (см. выше).

## Структура

```
project.yml              — описание проекта для XcodeGen
Shared/SiteStats.swift   — модель JSON и загрузка people.num
Widget/PtmobWidget.swift — виджет (таймлайн и вид для трёх размеров)
App/PtmobStatsApp.swift  — приложение-контейнер (нужно macOS для виджета)
build.sh                 — сборка и установка одной командой
```
